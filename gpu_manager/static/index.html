Адміністрування GPU та моделей
Журнал
    Як користуватися

    Оберіть себе вгорі («Хто я?») — запам'ятається. Без цього можна лише дивитися.

    GPU

    • Стан кожної карти щосекунди: температура, завантаження, потужність, пам'ять, процеси (натисніть — команда), моделі з портами.
    • Колір: звичайна — вільна; синя — заброньована; жовта — працює без бронювання (процес чи модель) або строк бронювання минув; червона — немає даних.
    • «Зайняти» — позначити карту своєю (мета, строк); «Звільнити» — коли закінчили; «Зняти» — чуже бронювання, лише за домовленістю.

    Моделі

    • Пошук на HuggingFace; натисніть на модель — «чи влізе» в карту і «Завантажити».
    • Один список; галочки «запущені» / «завантажені» — що показувати.
    • «Новий запуск»: карта і частка пам'яті повзунком; «макс» — менеджер підбере сам (найбільше пам'яті й контексту).
    • Під запущеною моделлю: її стан, стан карти, «назва для агентів», «Лог», «Зупинити». Інша карта чи порт → «Змінити» (перезапуск на новому місці) або «Скасувати».

    Чат

    • Виберіть запущену модель і пишіть; Ctrl+Enter — надіслати, «Зупинити» — обірвати відповідь, «Почати розмову» — з чистого аркуша.
    • 📎 — файли, Ctrl+V — картинка з буфера. PDF: «як є», «текст» або «зображення» (сторінки картинками — для моделей із «зором»). Що прийняти — вирішує модель.
    • Розмова живе, поки відкрита вкладка браузера; назавжди нічого не зберігається.
